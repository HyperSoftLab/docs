# Раскатка агентов мониторинга для контура 1С

## Общие положения

В рамках данной инструкции предполагается, что система GMONIT уже развернута:
- на выделенной виртуальной машине для мониторинга 1С;
- либо в конфигурации **All-in-One** (по согласованию с заказчиком).

## Порядок установки

1. **Установка инфраструктурных агентов**

   Установить инфраструктурные агенты на:
   - серверы 1С;
   - серверы СУБД.

   Для серверов СУБД дополнительно необходимо установить соответствующее расширение инфраструктурного агента для сбора метрик используемой системы управления базами данных (например, Microsoft SQL Server, PostgreSQL и др.).

2. **Установка агента мониторинга кластера 1С**

   Установить агент мониторинга кластера 1С.

   Со стороны заказчика необходимо:
   - включить службу **RAS**;
   - создать пользователя `gmonit` и предоставить ему необходимые права доступа.

3. **Установка агента для сбора журнала регистрации (ЖР)**

   Установить агент для чтения журнала регистрации.

   Для минимизации нагрузки на серверы 1С рекомендуется:
   - предоставить общий доступ к каталогу с журналами регистрации;
   - смонтировать данный каталог на виртуальную машину, где размещен GMONIT;
   - выполнять чтение журналов с подключенного каталога.

   При такой конфигурации агенты не создают дополнительной нагрузки на серверы 1С.

4. **Установка агента для чтения технологического журнала (ТЖ)**

   Установить агент для чтения технологического журнала по аналогии с агентом чтения журнала регистрации.

   Для технологического журнала доступны готовые дашборды по следующим событиям:
   
   - DBMSSQL;
   - TLOCK;
   - TTIMEOUT;
   - SDBL;
   - EXCP;
   - CALL.
